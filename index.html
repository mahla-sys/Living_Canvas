Living Canvas — در حال بارگذاری بوم…

اگر این پیام بیشتر از چند ثانیه ماند، یعنی جاوااسکریپت اجرا نشده است.

مطمئن شو برنامه را با npm run dev اجرا کرده‌ای و آدرس http://localhost:3000 را باز می‌کنی — نه فایل html را مستقیم.

برای دیدن دلیل دقیق، F12 را بزن و تب Console را باز کن.

جاوااسکریپت مرورگر غیرفعال است — Living Canvas بدون آن کار نمی‌کند.
